# Wonder Maker (Alpha)

A fan-made recreation of **Mario Maker** for **PC and Android**, featuring two playable game styles: **Super Mario Bros.** and **Super Mario Bros. 3**.

The project aims to recreate the core Mario Maker experience while adapting it to its own scope and limitations.

## Features

* Available for PC and Android
* Level creation inspired by *Mario Maker*
* Two game styles:

  * Super Mario Bros.
  * Super Mario Bros. 3
* Custom gameplay systems and mechanics
* Built with Godot 3.6

## Development

The project was made using **Godot 3.6**.

The last major update to this version of the project was released in **2025**. This version of the source code is **no longer in active development**.

However, the **Wonder Maker** idea itself is still being developed. The project is currently being rebuilt from scratch using a completely new codebase.

## Status

**This repository represents an older version of Wonder Maker (Old Alpha).**

Development of this specific codebase has ended, but the project itself is still alive and being rewritten from the ground up.
